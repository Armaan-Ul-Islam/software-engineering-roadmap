How to use this page
  1. 1. Start with the map below. Arrows point from a prerequisite to what builds on it. Click a domain to jump to it.
  2. 2. Each domain is a checklist. Tick an item when you can explain it to a colleague without notes and have used it at least once.
  3. 3. Items marked notes open a short explainer right here. The other chips open the best external resource for that item in a new tab.
  4. 4. Pick a track in the top bar to time-box the roadmap: only the track's items are shown, and every progress bar then measures the track instead of the whole map.
  5. 5. Progress is saved in this browser only. Use Export to back it up or move it to another machine, and Import to restore it.
  6. 6. Read the roadmap source on GitHub if you prefer plain markdown; every checklist and note is a file in the repository.
