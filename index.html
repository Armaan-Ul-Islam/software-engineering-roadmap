How to use this page
  1. 1. Start with the map below. The domains are numbered in the order the sixty-day track takes them, but none is a prerequisite for another: start anywhere and run several side by side. Click a domain to jump to it. Two optional domains (AI Engineering, Projects) sit behind the More button under the list.
  2. 2. Each domain is a checklist. Tick an item when you can explain it to a colleague without notes and have used it at least once.
  3. 3. Items marked notes open a short explainer right here. The other chips open the best external resource for that item in a new tab.
  4. 4. Pick a track in the top bar to time-box the roadmap: only the track's items are shown, each item carries its Day badge, the map shows which days cover each domain, and every progress bar then measures the track instead of the whole map.
  5. 5. Pick or create a profile (your name). Your ticks are kept in this browser under that profile. To keep them for good, click Save file and put the downloaded <profile>.json into the repository's progress/ folder (commit it, or upload it through GitHub's "Add file"); the site rebuilds and every device starts from it. Copy link gives you a link that carries your progress for a quick transfer.
  6. 6. Read the roadmap source on GitHub if you prefer plain markdown; every checklist and note is a file in the repository.

The map

The thirteen core domains in reading order, top to bottom. Nothing is a prerequisite for anything else; the order is only the one the sixty-day track follows. Progress is shown inside each node.

Optional

Extra domains for after the core, or when a task at work needs them. They are not part of the sixty-day track and do not count towards the progress bar in the top bar.
